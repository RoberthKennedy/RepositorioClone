📌 Novos Recursos: Busca de Repositórios

Este projeto recebeu melhorias na função de busca de repositórios, tornando a experiência mais completa e informativa para o usuário.

Agora, ao pesquisar um repositório, são exibidas informações adicionais, incluindo:

⭐ Estrelas (Stars)

Mostra quantas pessoas favoritaram o repositório no GitHub — uma forma rápida de entender sua popularidade.

🍴 Forks

Indica quantas cópias do repositório foram feitas por outros desenvolvedores. Isso ajuda a entender o nível de colaboração ou reutilização do projeto.

⏰ Data do Último Push

Exibe a última vez que o repositório recebeu atualizações de código (geralmente o último commit enviado).
Essa informação é útil para saber se o repositório está ativo ou abandonado.
